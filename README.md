# OmniShell 📱🛠️

An advanced, responsive Android system control app built specifically for phones and tablets (like the Samsung Galaxy Tab A7 SM-T505). 

## 🧠 The Philosophy
This project is **100% vibecoded**. 

Let's be real: learning entirely new programming languages, messing with Gradle, and wrestling with KTS configurations just to build one or two hobby projects is an absolute headache. This app was built purely for fun, by a hobbyist, using Gemini to do the heavy lifting. It isn't meant to be "professional" or a commercial product—it's built to explore, control the system, and experiment on my terms.

## 🚀 Features (In Progress)
- **Universal Scaling:** Automatically resizes itself cleanly for tiny phone screens up to large 10.4-inch tablet displays.
- **System Monitoring:** Keeps tabs on CPU, RAM, storage, and battery metrics.
- **Device Control:** Standard non-root tweaks (brightness, screen rotation toggle, volume, system info).
- **Future Root Architecture:** Built-in structural hooks that will unlock heavy-duty system file modifications and advanced shell commands once the device gets root access.

## 🛠️ Tech Stack & Development
- **Language:** Written in Kotlin/XML (via AI generation)
- **IDE:** Android Studio
